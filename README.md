# 教習所予約・空き枠ウォッチャー

GitHub Actions が予約サイトへログインし、今日を含む7日間の空き枠を確認してDiscordへ結果を通知します。PCを起動しておく必要はありません。

## 使い方

1. このフォルダを **公開 GitHub リポジトリ**として push します。公開リポジトリの Actions は無料です。ログイン情報はコミットしません。
2. Discord の通知用チャンネルで「チャンネルの編集 → 連携サービス → ウェブフック」を作成し、Webhook URL をコピーします。
3. GitHub のリポジトリで `Settings → Secrets and variables → Actions → New repository secret` を開き、`USERNAME`（教習生番号）、`PASSWORD`（暗証番号）、`DISCORD_WEBHOOK_URL` を登録します。値だけを入力し、`.env` は push しません。
4. `Actions → Check driving-school vacancies → Run workflow` でテスト実行します。

## 判定内容

光悦自動車教習所の予約サイト用です。「実車」を選択した後、予約表内の `td.Aki`（ピンクの空きコマ）を取得し、要素IDの `YYYYMMDD時限` を通知します。通知対象は日本時間の今日から6日後までです。新しい空きがない場合も、確認時刻と現在の空き数をDiscordへ通知します。予約操作はしません。

## 運用上の注意

- スケジュールは日本時間で終日15分ごと（`:00`、`:15`、`:30`、`:45`）です。GitHub Actionsの定期実行には多少の遅延がありえます。
- CAPTCHA、ワンタイムパスワード、アクセス自動化の禁止があるサイトでは、この方式は動かせない・使えない場合があります。サイトの利用規約を確認してください。
- 非公開リポジトリではGitHub Actionsの無料枠に上限があります。ゼロコストを確実にするには公開リポジトリを使い、Secretsで認証情報を保護してください。
